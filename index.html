    Profile

    Engineer for regulated, high-stakes systems

    Four years building software where correctness matters: loan approvals, credit limits, guarantees, supply chain invoices and network inventory.

    I'm a software engineer specializing in Java Spring and Spring Boot, with deep experience integrating with T24, one of the leading core banking systems.

    That work has taught me how to build scalable, efficient solutions for the financial industry. I enjoy hard problems, and I keep learning so each project gets my best work.

    At eMcReY I lead development of ECLO, a credit approval platform, and eTrade, which issues Letters of Guarantee and Letters of Credit against ECLO's approved limits. I'm now building a supply chain module that extracts suppliers, beneficiaries and invoices into Java models and runs them through our workflow engine. I integrate these systems with T24 core banking and ECM, tune Oracle SQL, deploy on Linux across DEV, SIT and UAT, and work with DevOps on CI/CD.

    Before that, at MobiNetS, I built core features of NEP, a network engineering platform used by major network providers to model cabinets, shelves, ports and topology. I also led its UI migration from Polymer to Vaadin.

    Beyond coding, I care about knowledge sharing and community building. I mentor junior developers, run code reviews, and led my university's Google Developer Student Club. In my own time I build with Python and Django: a personal finance tracker now, and an AI support assistant next.

    I'm always glad to connect with other engineers. Reach out to discuss opportunities or exchange ideas.
